# Changelog

All notable changes to ibex are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-27

First public release. Linux only (.deb and .rpm, x86_64), for Ubuntu 24.04, Debian 13, Fedora 40 or newer.

### Added
- Open unencrypted and encrypted iPhone backups (Finder/iTunes or `idevicebackup2`), strictly read-only.
- Messages: SMS, MMS and iMessage with attachments, contact names, reactions, replies, edited and unsent markers.
- WhatsApp and WhatsApp Business: chats, groups, media, locations, contact cards, voice notes.
- Photos: camera roll grid, albums, Live Photos, HEIC display, recently deleted and hidden.
- Voice Memos, Files ("On My iPhone" and per-app Documents), Contacts, Call History.
- Full-text search across SMS and WhatsApp (Ctrl+K).
- Raw browser for every domain and file, with image, text, plist, PDF, audio/video and hex previews.
- Export to offline HTML, CSV, JSON, vCard, or original files with original names and timestamps.
- `ibex-cli`, a command-line tool over the same core library.
